# Current design and build scope

Updated 2026-10-11. Brad has accepted the published compact interface and its signed-out/signed-in request flows.

The primary experience is the Home request/result workspace, with saved named lists, inline permission confirmation and compact results. Sign In, Permissions, Activity and Security / Identity support that workflow. Identity detail stays secondary.

Maintain readable responsive layouts, scrollable long results, visible action controls, green success and red blocked/error feedback. Public examples remain usable without sign-in. Only personal or permission-management actions request authentication.

Broad policy dashboards, deployment navigation, advanced proposal/approval dialogs and unavailable microphone controls have been removed from the main UI. Do not restore them as submission requirements.
